## Executive Summary & Epistemic Rules

This registry inventories every material coverage rate, package yield, waste/settling/compaction allowance, density constant, spacing standard, opening deduction, and geometric/sizing rule across all 15 calculators, engines (`src/scripts/calculators/*.ts`), UI wrappers (`src/pages/*CalculatorPage.tsx`), guides (`src/data/guides*.ts`), and methodology disclosures (`src/pages/MethodologyPage.tsx`).

**Epistemic Integrity Standard:**
- **Zero Fabrication:** No external URLs, ASTM/IRC clause numbers, or manufacturer Technical Data Sheet (TDS) measurements have been invented from memory.
- **Verification Status:** Because primary external standards and manufacturer TDS documents have not yet been retrieved, archived, and cited with explicit revision dates inside the repository, **all technical assumptions requiring external empirical grounding are marked `UNVERIFIED`** pending Phase 2B primary-source collection. Exact geometric identities (e.g., `1 cu yd = 27 cu ft`, `1 sq ft = 144 sq in`, Pythagorean roof pitch multiplier `√(1 + (rise/12)²)`, cylinder volume `πr²h`) are marked `MATHEMATICAL IDENTITY` where pure geometry applies, while their chosen engineering inputs/defaults remain `UNVERIFIED` against external guidelines.
- **High-Severity Inconsistencies Found:** Several critical discrepancies exist *within* the current codebase (e.g., unused UI input `groutJointWidthInches` in `tile.ts`; `MethodologyPage.tsx` contradicting `mulch.ts` and `gravel.ts`; `fenceMaterial.ts` vs `concretePostHole.ts` concrete bag yields; `HomePage.tsx` showcase examples contradicting engine outputs).

## Cross-Cutting Findings Summary (System-Wide Technical Conflicts)

1. **Unused UI Parameter (`tile.ts`):** `groutJointWidthInches` is selectable in UI and advertised in copy/guides, but is ignored by `calculateTile()`.
2. **Pricing Quantity & Unit Bugs (`paverPatio.ts`, `roofing.ts`, `drywall.ts`, `flooring.ts`, `fenceMaterial.ts`, `deckMaterial.ts`):**
   - `paverPatio.ts`: Bills net `patioArea` instead of waste-adjusted area; guide `benchmarksNote` uses per-unit (`$1.25/paver`) while `prices.ts` uses per-sq-ft (`$4.50/sq ft`).

   - `drywall.ts`: BOM/cost mismatch between `DrywallCalculatorPage.tsx` (`companionBOM`) and `drywall.ts` (`costEstimate`); flat `$25` kit regardless of room square footage; ignores `4×12` price.
   - `flooring.ts`: Silently maps `laminate` to `'flooring-lvp'`.
   - `fenceMaterial.ts`: Always prices `8'` posts, `8'` rails, and `6'` pickets even when user chooses `4'` or `8'` fence height or `6'` post spacing.
   - `deckMaterial.ts`: Prices composite boards only while BOM mentions nominal 6" boards, UI adds unpriced framing/fasteners referencing nonexistent price IDs, and `costEstimate` pairs board-only materials with full turnkey structural deck labor (`$30/sq ft`).
3. **Methodology & Homepage Copy vs. Engine Contradictions:**
